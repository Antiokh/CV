# Application Pack Template

This is the standard structure for application packs in this repository.

## English pack

Use when the vacancy or contact flow is English.

Files:
- `resume_en.md`
- `resume_en.pdf` (optional but preferred)
- `cover_letter.md` or `cover_letter_ats.md`
- `cover_letter.pdf` (optional but preferred)
- `fit.md` or `why_me.md`
- `questions.md`
- `negotiation_strategy.md`
- `notes.md`
- `job_description.md`
- optional `README.md` for pack contents

## Russian pack

Use when the vacancy or contact flow is Russian.

Files:
- `resume_ru.md`
- `resume_ru.pdf` (optional but preferred)
- `cover_letter_ru.md`
- `cover_letter_ru.pdf` (optional but preferred)
- `fit_ru.md` or `why_me_ru.md`
- `questions_ru.md`
- `negotiation_ru.md`
- `negotiation_ru.pdf` (optional but preferred)
- `notes_ru.md`
- `job_description_ru.md`
- optional `README.md` for pack contents

## Mixed-language pack

Use only when the role or company context clearly benefits from it.

Recommended rule:
- keep the core resume in one language
- add only a short alternate-language intro if needed
- do not mix languages line-by-line inside the main resume

## Standard content

A full pack should usually include:
- resume
- cover / intro note
- role fit memo
- questions for the interview
- negotiation strategy
- notes / reminders
- job description or role context
- optional PDFs for the main documents

## Sending rule

If the pack is ready, send it as a **single zip archive**.
