# Anti Patterns

Use this file to prevent narrative contamination between tracks.

## General

Avoid:
- mixing all profile sides at once
- inventing metrics, scope, team size, or ownership
- sounding like generated corporate filler
- using unsupported prestige signals
- over-polishing real experience until it loses Anton's human voice

## Managerial / Executive

Avoid:
- long stack lists
- presenting Anton as primarily a no-code builder
- freelancer framing
- Upwork-style selling
- "I build apps/websites"
- feature-level implementation details as the main story
- tools as the center of the narrative

## Technical Delivery / Specialist

Avoid:
- vague transformation rhetoric without technical proof
- hiding technologies, architecture, or integrations
- making management language dominate the story
- sounding like a pure people manager if the role is hands-on

## Upwork / Freelance

Avoid:
- title inflation
- enterprise abstraction without practical delivery proof
- generic agency tone
- excessive biography before showing relevance

## NeedleBit Marketing

Avoid:
- cheap dev shop framing
- no-code agency framing
- feature factory framing
- "fast MVP" as the main message
- panic-based pain marketing
- AI hype without operational credibility
- treating old NeedleBit archive materials as current messaging

## Interview / Self-positioning

Avoid:
- generic motivational fluff
- polished but unsupported stories
- rewriting history to fit a role
- flattening the profile into only developer or only manager

## Resume / ATS / AI Detector

Avoid:
- perfectly symmetrical skill taxonomies as the main resume structure
- list-heavy sections where every line has the same rhythm
- summaries made only of abstract nouns like delivery, governance, transformation, architecture, implementation
- dense technology blocks that are disconnected from real project situations
- deleting true ATS keywords only to reduce detector scores
- claiming detector checks were completed when a service returned 403, 429, 401, or no usable score
- treating short factual list false positives, such as languages, as proof that the whole resume is AI-generated
