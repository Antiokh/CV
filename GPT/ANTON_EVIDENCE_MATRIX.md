# Anton Evidence Matrix

This file is the canonical **routing index** from hiring expectations to Anton Nazarov's strongest supported evidence.

It is not the source of truth for raw facts. Detailed facts remain in canonical CV/source files. This file exists so vacancy adaptation does not repeatedly rediscover the same proof or choose a weaker signal because it is easier to phrase.

Use with:

- `GPT/EXPECTATION_TAXONOMY.md` — expectation definitions and 0–5 strength scale;
- `GPT/ROLE_SIGNAL_PROFILES.md` — role-family ordering and first-screen logic;
- `RESUME.md` — evidence-rich master resume;
- `details/hiring_filter_signal_review_2026-09-15.md` — observed current hiring filters;
- source/debrief files listed under each evidence block.

## Evidence status labels

- **documented** — supported by stored documentary/project evidence;
- **user-confirmed** — Anton explicitly recalled and confirmed the fact; defensible if he can explain it in interview;
- **estimate** — approximate number or market/economic estimate; qualify as approximate and do not strengthen causality beyond the source;
- **mixed** — core fact documented, some context/outcome from user-confirmed debrief.

Do not expose these labels in candidate-facing CV text. They are internal provenance only.

## Selection rule

For each vacancy expectation:

1. choose the **highest-strength evidence that proves that exact expectation**;
2. prefer same-domain evidence when strength is comparable;
3. prefer memorable before/after outcomes over generic scope;
4. preserve explicit hard-filter evidence even when a different business result is more impressive;
5. never use a secondary scale metric as a substitute for the wrong expectation;
6. if all available evidence is 0–2 for a MUST filter, record a real gap rather than hiding it.

The master resume may contain many blocks. A tailored CV should normally expose only the subset that maximizes **first-screen evidence coverage** for the concrete vacancy.
