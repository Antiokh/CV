# Agent Portfolio Navigator

This file is the entry point for any agent working on portfolio case studies in this repository.

## Goal

Help an agent add, rewrite, or expand project case studies without guessing local conventions.

## Read Order

1. [Portfolio Index](./README.md)
2. [Agent Project Intake Guide](./agent_project_intake_guide.md)
3. [Agent Case Study Format](./agent_case_study_format.md)

## Use This When

- adding a new project to `portfolio/`
- rewriting an existing project `README.md`
- normalizing screenshots, media naming, or case-study structure
- checking whether a case is strong enough for public-facing use

## Agent Rules

- Treat each project folder as a public-facing case-study package.
- Keep the main `README.md` concise and scannable.
- Prefer explicit ownership, system behavior, constraints, and results over tool dumps.
- Use English.
- Use lowercase project folder names with underscores.
- Keep media inside `media/`.
- Prefer descriptive filenames for any media that is linked publicly.

## Minimum Deliverable

If updating a project, the agent should leave behind:

- a stronger `README.md`
- cleaner media references if needed
- an updated [Portfolio Index](./README.md) if a new case was added

## If Information Is Incomplete

If metrics are missing, still make the case useful by emphasizing:

- scope
- ownership
- complexity
- constraints
- architectural decisions
- workflow or operational improvement
