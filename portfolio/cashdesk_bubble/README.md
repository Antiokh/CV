# Cashdesk Accounting - Financial Management System

## Overview

Cashdesk Accounting is an internal financial management system designed to replace and improve an existing accounting workflow with clearer permissions, transaction handling, cash operations, and export-ready reporting.

The project started without a clean specification and required analysis of the existing system, redesign of the user experience, and pragmatic delivery within budget constraints.

The result was a more secure and scalable internal financial tool with better control and decision support.

---

## What the System Does

- Manage user rights and access control
- Support cashdesk and transaction workflows
- Track financial operations in a structured way
- Produce CSV-based reports and exports
- Improve session security through auto-logout behavior

---

## Key Features

### Rights and Permissions
The system includes role-aware access logic to improve operational control and reduce risk.

---

### Transaction and Cashdesk Management
Core financial actions were reorganized into a more structured and manageable workflow.

---

### CSV Reporting
The product supports export-oriented reporting to help financial review and downstream processing.

---

### Security Improvements
The implementation included auto-logout behavior and stronger UX around safe use of the system.

---

### UX Redesign
Rather than copying the previous product mechanically, the system was rethought from the user-experience side to make financial work more understandable and efficient.

---

## Tech Stack

- **Platform:** Bubble.io
- **Output:** CSV exports
- **Security:** Auto-logout and access-control logic

---

## Challenges

### No Clear Specification
The project required reverse-engineering and analysis of the previous system before the new one could be designed properly.

---

### Budget Constraints
The implementation had to stay practical and efficient while still improving the system meaningfully.

---

### Financial UX Requirements
Financial tools need clarity and reliability, which made interface and flow design more important than in a generic internal CRUD product.

---

## Result

The system improved financial control, made decision-making easier, strengthened security, and created a more scalable internal accounting workflow.

---

## Key Takeaway

This project demonstrates the ability to redesign a business-critical internal tool under ambiguity, balancing analysis, UX, security, and pragmatic delivery constraints.
