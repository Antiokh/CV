# French Plumbers ERP - Internal Operations Platform

## Overview

This project was an ERP system for a French plumbing business, built with WeWeb on the frontend and Supabase on the backend.

The product was positioned as an internal operational platform rather than a public-facing website, with the goal of supporting business workflows in a more structured and scalable way.

---

## My Role

Full Stack Developer

---

## What the System Does

- Support internal ERP-style workflows for a plumbing business
- Provide a custom web interface for operational tasks
- Connect frontend workflows to a Supabase-backed data model
- Turn design concepts into a working business application

---

## Key Features

### WeWeb + Supabase Architecture
The system used WeWeb for the frontend layer and Supabase as the backend foundation, giving the product a fast but structured full-stack architecture.

---

### Internal Business Workflow Focus
The project was built as an ERP-style internal tool, which makes it more about operational structure and business process support than about marketing or presentation.

---

### Design-to-Code Delivery
Part of the value in the project was translating product and interface design into a working application with real data flows behind it.

---

## Tech Stack

- **Frontend:** WeWeb
- **Backend:** Supabase

## Challenges

### ERP Scope in a Low-Code Stack
Building an ERP-style product requires more structure than a typical landing page or lightweight app, especially when the goal is to support real internal operations.

---

### Turning Design Into Working Operations
The project required moving from interface design into a usable operational product, which means handling both frontend execution and backend structure coherently.

## Result

A working ERP-oriented product foundation for a French plumbing business, built with WeWeb and Supabase as a practical internal system rather than a superficial prototype.
