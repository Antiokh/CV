# Sources

This folder contains evidence and provenance material used to build Anton Nazarov's profile and CVs.

## Employment evidence — canonical routing

For employment history, **do not start from loose debrief files**.

Start from [`sources/employers/README.md`](./employers/README.md) and load the dossier for the relevant employer.

The employer dossiers consolidate facts that were previously scattered across:

- raw voice-dictated career notes;
- old CVs;
- project portfolio files;
- dated ChatGPT debriefs;
- `cross_role_*` notes;
- employer-specific notes such as `zil.md` / `mosrazvitie.md`.

Those older files are deliberately retained as **provenance / archive material**. They remain useful for checking where a fact came from or recovering details, but they should not normally be treated as independent competing summaries after the fact has been consolidated into an employer dossier.

When new employment evidence appears, update the relevant employer dossier first, then update `GPT/ANTON_EVIDENCE_MATRIX.md`, role profiles and CVs as needed.

## Provenance rule

Source/confidence/provenance language belongs here, not in candidate-facing CV text. A CV states a verified fact directly; it must not say `according to source`, `documented baseline`, `user-confirmed`, etc.

Do not delete raw/debrief material merely because it has been consolidated. Employer dossiers are the canonical **working layer**; raw files are the audit trail.
