# Additional experience evidence

This directory stores career evidence that is real and potentially useful but does not map cleanly to one employer dossier.

Use it for:

- event / festival / volunteer leadership;
- promotion / SMM / audience-facing work;
- transition periods between formal employers;
- other cross-career experience that should not be forced into a company record.

Employer facts remain canonical under `sources/employers/`. When an item here clearly belongs to one employer, move or cross-reference the fact into that employer dossier rather than duplicating competing versions.
